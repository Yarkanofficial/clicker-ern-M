## 📌 About

**ClickArena** is a competitive click-based game where users compete daily to get the most clicks. The top 4 winners of each day share **70%** of the total pool, while the owner receives **30%**.

### 🎯 Features

- ✅ User Registration & Login
- ✅ Daily Click Competition
- ✅ Real-time Global Click Counter
- ✅ 24-Hour Timer
- ✅ Subscription Plans (1, 7, 14, 30 Days)
- ✅ USDT TRC20 Deposits & Withdrawals
- ✅ Daily Winners Leaderboard
- ✅ User Rank Display
- ✅ Responsive Design
